# KPM — المشروع كامل

## تشغيل المشروع

1. فك الضغط عن المجلد
2. افتح المجلد في VS Code
3. في التيرمينال:

```bash
npm install
npm run dev
```

4. افتح المتصفح على: http://localhost:3000

## الصفحات

| الرابط | الصفحة |
|---|---|
| `/` | Home |
| `/LessonsLearned` | Lessons Learned |
| `/LessonDetails` | تفاصيل الدرس |
| `/CreateLesson` | إنشاء درس + Review Summary |
| `/Chatbot` | الـ AI Assistant |

## الثيم (أسود / أبيض)

- الأسود هو الأساسي
- زرار ☀️ / 🌙 في النافبار بيقلب الثيم
- الألوان كلها متعرّفة في `app/globals.css` تحت `:root` (أسود) و `.light` (أبيض)

## الحاجات المستخدمة في الكود

- Function Components + Props
- `.map()` لرسم الكروت واللينكات
- CSS Modules لكل كومبوننت
- `useState` في زرار الثيم بس
- `usePathname` للينك النشط في النافبار
- CSS Variables للثيم
